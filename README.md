# HOW TO USE.
This section teaches you how to use the launcher

## Download.
Download the Universal Release Candidate pyz file from the releases page:

https://github.com/JusTAnoThErD3v/BeetRootMC/releases/tag/Release-Candidate

## Dependencies.
Install Python 3.14 on your system from:

https://www.python.org/downloads/release/python-3140/

You will also need Java (minimum Java 17 but anything above will work)

## Running the pyz.
Run the .pyz file using the python3.14 or python3 command specific to your os.
